# A Combined Experimental and Computational Study of the Cell Wall Properties in Tip-Growing *Physcomitrium patens*

**Lucas Ramondo, Rholee Xu, Professor Vidali, Professor Wu**
Bioinformatics and Computational Biology Program, Worcester Polytechnic Institute

Manning and Leser Summer Fellowship & Associate Bioinformatics Researcher

📄 [Full Poster (PDF)](./poster/RAMONDO_wpi_final_poster.pdf)

## Overview

This project investigated two open questions about how tip-growing plant cells regulate their cell wall mechanics, using *Physcomitrium patens* (a moss) as a model organism:

1. **Is there an elastic gradient in the cell wall**, with the wall material becoming looser toward the growing tip?
2. **Is there a pH gradient at the tip**, consistent with proton-pump-driven activation of expansin proteins that loosen the wall?

## My Contributions

- Loaded and imaged live *P. patens* protonemata using a microfluidic flow-through system paired with spinning disk confocal microscopy
- Induced plasmolysis (via mannitol treatment) to quantify cell wall shrinkage and triangulate elastic properties, comparing caulonema vs. chloronema cell types
- Applied and compared pH-sensitive (pHrodo Green) vs. pH-independent (Alexa Fluor) fluorescent dyes to profile pH distribution along the cell wall
- Used Fusicoccin treatment to activate proton pumps across the whole cell and test whether the pH gradient could be flattened
- Contributed to a 3D surface model of the cell wall using fluorescent bead tracking and surface triangulation — a methodology that has since been published

## Key Findings

- Mannitol-induced plasmolysis caused measurable cell wall shrinkage, with caulonema cells shrinking more on average than chloronema cells
- Preliminary fluorescence data suggests a more acidic pH at the cell tip compared to the sides of the wall, consistent with the hypothesis
- Control experiments (pH-independent dye, Fusicoccin treatment) did not fully flatten the expected fluorescence profile, pointing to open questions for further investigation

## Tools & Techniques

Spinning disk confocal microscopy, microfluidics, fluorescence imaging (pHrodo Green, Alexa Fluor), plasmolysis assays, image analysis (ridge detection, z-projection), 3D surface triangulation modeling, MATLAB & Python data processing

## Future Work

- Additional fluorescence data collection across controls
- Calculating a pHrodo Green–to–Alexa Fluor ratio for more precise pH identification
- Statistical confirmation of fluorescence distributions
- Comparing pH distinctions between caulonema and chloronema cell types
